RUANG ARTIKEL - UPGRADE TAHAP 2 & 3
1. Masukkan folder project ke Termux.
2. Jalankan: node server.js
3. Buka http://127.0.0.1:3000
4. Registrasi akun pertama menjadi ADMIN. Daftarkan akun admin tepercaya dahulu.
5. Akun berikutnya menjadi USER.
6. Database permanen: data/db.json
7. Upload gambar: public/uploads/
8. Admin bisa menyetujui atau menghapus komentar pending.
9. Artikel user hanya dapat diubah/dihapus pemiliknya. Admin memiliki akses penuh.
Penting: Backup data/db.json dan folder public/uploads secara berkala. Jangan membagikan password.
